# spyglass documentation

## Configuring global settings

You can change the colour scheme and amount of image workers in the `globalconfig.toml` file.

```toml
# ~/.config/spyglass/globalconfig.toml
search_icon_colour = "#cba6f7"
search_box_border_colour = "#cba6f7"
list_border_colour = "#cba6f7"
list_highlight_colour = "#cba6f7"
list_description_deselected_colour = "#1e1e2e"
lens_colour = "#f9e2af"
image_workers = 8
```
